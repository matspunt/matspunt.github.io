# Personal blog

Hi, this is my personal blog, adapted from the [Mundana](https://github.com/wowthemesnet/mundana-theme-jekyll) Jekyll theme. I have removed functionality such as comments, authors, tags and significantly simplified the UI to remove clutter. The theme was originally published under the MIT License and that means mine is too. All images used are from the Free tier of [Unsplash](https://unsplash.com/)

- To make a post 'stick' at the top of the page and highlight it, include ```tags: [sticky]``` with the Markdown in the post. 
- Jekyll and Liquid are notorious for their excessive presence of whitespaces, [compress.html](https://jch.penibelst.de/) is used to mitigate this.
